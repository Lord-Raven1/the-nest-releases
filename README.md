<h1 align="center">The Nest</h1>
<p align="center"><em>When certainty needs a guarantee.</em></p>

The Nest keeps automatic backup copies of the files you're working on. Every five minutes it checks the files and folders you've added. If anything changed, it saves a copy somewhere safe on the same computer, keeping the last five good versions of each file.

Every copy gets a health check first. A damaged save is flagged and kept to one side, so it can never push out a good version.

## Download

Get **The Nest.exe** from the [latest release](https://github.com/Lord-Raven1/the-nest-releases/releases/latest). It's a single file, with nothing to install.

Windows may show *"Windows protected your PC"* the first time, because the app isn't signed by a publisher. Click **More info → Run anyway**.

**To update:** quit The Nest, replace the exe with the new one, and open it again. Your settings and backups are stored separately, so nothing is lost.

## Privacy

The Nest never connects to the internet. There are no accounts and no cloud, and it collects nothing. Backups stay in your own Windows profile (`%LOCALAPPDATA%\The Nest`), or on a drive you choose.
