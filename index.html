How it works

Three steps, and only the first one is yours.

  1. Add what you're working on

    Pick a single document or a whole folder. Word, Excel, PowerPoint, PDFs, images, text, anything.

  2. The Nest keeps watch

    Every five minutes it checks for changes. If a file changed, it saves a fresh copy. If nothing changed, it saves nothing.

  3. Take any version back

    Open an old copy, save it somewhere new, or put it back where it was. Lock files and temp files are ignored.

The guarantee

A bad save can't push out a good one.

Most backup tools keep the last few copies, whatever state they're in. Save a broken file five times and every good copy is gone.

The Nest keeps two shelves. Good versions rotate on one; damaged ones are held on the other for reference. Try it.

Privacy

Your documents never leave the nest.

The Nest has no internet code at all. There is nothing to sign in to and nothing to sync. Copies sit in your own Windows profile, readable only by your account, or on a drive you choose.

No internet

It never connects to anything. It works the same with Wi-Fi off.

No account

No email, no sign-up, no licence server. Open it and it works.

No cloud

Nothing is uploaded. It works where OneDrive and AutoRecover are switched off.

Yours only

Backups live under your Windows account, not in a shared folder.
